# Online Examination System

## 📌 Project Overview

The Online Examination System is a web-based application that allows students to register, log in, take online examinations, and view their results and exam history.

Administrators can create examinations and add multiple-choice questions.

## 🚀 Features

### Student
- Student Registration
- Student Login
- Student Dashboard
- View Available Exams
- Exam Instructions
- Online MCQ Examination
- Countdown Timer
- Next/Previous Questions
- Automatic Evaluation
- View Results
- Exam History

### Admin
- Admin Login
- Admin Dashboard
- Create Examination
- Add Questions

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- SQLite
